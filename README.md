## 🌟 About

File Store Pro is a powerful Telegram file sharing bot designed to create secure shareable links, manage premium users, broadcast messages, and automate file delivery with advanced admin controls.

---

## 🚀 Features

### 🔗 Link Management
- Generate single file links using `/genlink`
- Create batch links using `/batch`
- Create custom batch links using `/custom_batch`
- Secure sharing system

### 👑 Premium System
- Add Premium Users
- Remove Premium Users
- Premium Expiry Support
- Check User Plans
- Premium User List

### 📢 Broadcast System
- Normal Broadcast
- Delete Broadcast
- Pin Broadcast
- Media Broadcast Support

### 👨‍💻 Admin Controls
- Add Admin
- Remove Admin
- Admin List
- User Management

### 🚫 User Management
- Ban Users
- Unban Users
- Ban List
- Request Cleanup

### 📂 Force Subscribe System
- Multiple Channels Support
- Add Channel
- Remove Channel
- View Channels
- Enable / Disable FSub

### 🗑 Auto Delete
- Set Delete Timer
- Check Delete Timer
- Auto Cleanup System

### 📊 Analytics
- Bot Statistics
- User Count
- Database Count
- Uptime Monitoring

### 🔐 Security
- Token Verification
- Protected Content Support
- Secure File Delivery

OWNER_ID=

## Database

```env

```

## Optional

```env

START_MESSAGE=
PROTECT_CONTENT=True

cd FileStore

pip3 install -U -r requirements.txt

python3 bot.py
```
